# Модель телефона · State и Observer на C#

Учебное Windows Forms-приложение, моделирующее состояния телефона, входящий звонок, разговор и баланс. Две версии позволяют сравнить организацию кода и взаимодействие модели с интерфейсом.

[Модель](State1/State/Phone.cs) · [Контроллер](State1/State/PhoneController.cs) · [Портфолио автора](https://github.com/vokelilekov/Lilekov-221-3210-web-kurs/blob/main/PORTFOLIO.md)

## Что реализовано

- Состояния ожидания, входящего звонка, разговора и блокировки.
- Переходы через интерфейс `IState`.
- Пополнение баланса и разблокировка при неотрицательном остатке.
- Вероятностная имитация входящего звонка.
- Периодическое списание средств во время разговора.
- Уведомление наблюдателей о состоянии и балансе.
- В версии `State1` — отдельный `PhoneController` для команд интерфейса.

## Запуск

Нужны **Windows**, Visual Studio с компонентами разработки классических приложений .NET и Targeting Pack соответствующей версии .NET Framework.

```bash
git clone https://github.com/vokelilekov/TKPO_Lilekov.git
```

Откройте `State1/State.sln` для версии с контроллером или `State/State.sln` для первой версии. Соберите решение и запустите через **F5**. В `State1` используется `LangVersion=latest`, поэтому нужен компилятор с поддержкой синтаксиса C# 9 или новее.

## Как читать проект

Начните с `IState` и четырёх реализаций в `Phone.cs`, затем посмотрите `Phone.SetState` и уведомление наблюдателей. После этого перейдите к контроллеру и форме: так виден путь от нажатия кнопки до изменения модели.

## Известное ограничение

В `State1` метод `ConversationState.EndCall` переключает состояние, но не сбрасывает флаг `isTalking`. Поэтому запущенный цикл списаний может продолжаться после завершения разговора. Для доработки стоит связать жизненный цикл списаний с завершением состояния и проверить переходы отдельными тестами.
